## Directory structure


```
├── README.txt                # Project overview and instructions
├── archive/                  # Archived files (e.g., old versions, unused data)
├── code/                     # Scripts and source code
│   ├── src/                  # Self-contained, reusable functions and utilities that implement analysis capabilities without depending on project-specific data paths.
│   │   ├── r                 # R code
│   │   ├── py                # Python code
│   ├── scripts/              # Executable pipelines that load data, run deterministic analysis steps, and write intermediate or final results to disk.
│   └── notebooks/            # Interactive documents for exploration, visualization, and interpretation of results generated by the scripts.
├── data/                     # Raw and processed data
│   ├── raw/                  # Raw data (e.g., FASTQ, BAM)
│   ├── processed/            # Processed data (e.g., filtered, normalized)
│   └── metadata/             # Metadata files (e.g., sample information)
├── external_tools/           # External tools used
├── parameters/               # all parameters and configurations
├── planning/                 # Initial project planning files
└── results/                  # Analysis results
    ├── tables/               # Tabular results (e.g., CSV, TSV)
    ├── plots/                # Figures and visualizations
    └── logs/                 # Log files
```
